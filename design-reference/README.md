# DemoForge — Static design bundle

Six self-contained HTML pages plus a handoff doc, ready to share with Kiro / AgentSpace / engineering.

```
demoforge/
├── index.html         ← Landing / Welcome
├── home.html          ← Dashboard
├── generator.html     ← Generative-UI Generator (the hero page)
├── my-requests.html   ← My Requests + Answer Questions modal
├── admin.html         ← Admin Dashboard (5 tabs)
├── presentation.html  ← Fullscreen deck mode
├── _shell.css         ← Shared tokens / shell (reference only)
├── HANDOFF.md         ← Design spec + component library
└── README.md          ← This file
```

All HTML files are standalone — every page inlines its own CSS and SVG icons. Open `index.html` to start. Sidebar links connect every page in the suite.

See `HANDOFF.md` for the full design spec, token list, and Generative UI component library.
